Kontrol di bawah grafik dibuat otomatis oleh PyVis. Berikut panduan fungsinya:

Select a Network Item Pilih nama kota untuk menyorot bandara beserta seluruh rute penerbangan langsungnya.

Legenda Jaringan
  • Node (Bulatan): Merepresentasikan kota. Ukuran berbanding lurus dengan jumlah rute — semakin besar = Main Hub.
  • Edge (Garis): Jalur penerbangan langsung antar dua kota.
  • Interaksi: Geser graf, scroll untuk zoom, dan hover edge untuk lihat Harga (₹) & Durasi.
