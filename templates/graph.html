⚙️ Panduan Kontrol Navigasi

Menu dropdown di bagian bawah grafik dihasilkan otomatis oleh mesin analisis (PyVis). Berikut panduan fungsinya:

1. Select a Network Item Fitur Pencarian Kota: Pilih nama kota untuk menyorot (highlight) bandara tersebut beserta seluruh rute penerbangan langsungnya.
2. Select a Property Filter Kategori: Digunakan untuk memilih kategori penyaringan relasi penerbangan berbasis node.
3. Select values Nilai Filter: Setelah memilih kategori, gunakan menu ini untuk mengisolasi rute penerbangan tertentu di layar.

💡 Legenda Jaringan

  • Bulatan (Node): Menggambarkan Kota. Semakin besar bulatannya, semakin banyak rute yang lewat (Bertindak sebagai Main Hub).
  • Garis (Edge): Jalur penerbangan langsung antar kota.
  • 🖱️ Interaksi Mouse: Geser untuk memindahkan graf, gunakan scroll untuk zoom, dan hover kursor pada garis untuk melihat Harga (₹) & Durasi.
